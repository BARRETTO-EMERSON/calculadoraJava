# 🧮 Calculadora Java

Projeto desenvolvido em **Java** com o objetivo de praticar conceitos fundamentais da linguagem através da criação de uma calculadora interativa.

## 📋 Sobre o projeto

A aplicação permite ao usuário escolher uma operação matemática através de um menu e informar dois números para realizar o cálculo.

O programa continua funcionando até que o usuário escolha a opção **0 — Sair**.

## ⚙️ Funcionalidades

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* 🚪 Encerramento do programa
* ⚠️ Validação de divisão por zero
* 🔄 Repetição do menu utilizando `do while`

## 🧠 Conceitos praticados

Durante o desenvolvimento deste projeto foram utilizados conceitos básicos e importantes da programação em Java:

* `Scanner` para entrada de dados
* Variáveis
* Tipos `int` e `double`
* Operadores matemáticos
* Estrutura condicional `if/else`
* Estrutura de seleção `switch/case`
* Estrutura de repetição `do while`
* `break`
* Métodos de entrada e saída
* Organização e lógica de programação
